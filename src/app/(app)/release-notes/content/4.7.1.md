    detail: "Jobs are prevented from running twice by a uniqueness rule in the database. The code decided whether it had created a new job or joined an existing one from a row count that turns out to be identical in both cases, so a repeat trigger could be reported as a new run. It now detects the duplicate explicitly. Found by exercising the runner against a real database rather than in isolation."
