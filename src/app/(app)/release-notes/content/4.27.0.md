version: "4.27.0"
date: "2026-09-22"
title: "Invoices raised on any night inside the window"
summary: "The nightly cycle no longer waits for an expiry date to land exactly on a reminder offset. Any eligible outlet from 15 days out down to its expiry day gets a proforma on the first night it qualifies, so an expiry that moved, or a gap fixed between offsets, can no longer lapse with nothing raised."
new:
  - title: "Slurp logo on the renewal pages"
    detail: "The merchant-facing proforma and receipt now carry the real Slurp mark in the header instead of a placeholder initial. It sits on a light chip in dark mode so the wordmark stays legible without inverting the brand colours."
improved:
  - title: "Invoice generation follows a window, not three dates"
    detail: "Invoicing used to match each reminder offset as an exact expiry date, so an outlet was only ever invoiced on the night it sat exactly 15, 5 or 1 days out. An expiry date that moved — the POS sync correcting it, a renewal done outside SIMS, a hand edit — could step over all three and never be invoiced. The cycle now treats the furthest offset as the start of an invoicing window and raises a proforma for any eligible outlet inside it that does not already have one."
  - title: "A gap fixed between offsets no longer waits"
    detail: "An outlet blocked on its T-15 night by a missing plan or an unreachable PIC used to wait for the next offset before it was reconsidered. It is now invoiced on the very next nightly run after the gap closes."
  - title: "Queue entries sort by urgency on every night"
    detail: "An Actions Required entry raised on a night that is not a reminder offset now carries its real days-to-expiry instead of nothing, so the queue orders correctly."
fixed:
  - title: "Timeline no longer repeats the reminder cadence"
    detail: "Because the due pass now runs every night inside the window, only a night that lands on a configured offset records the cadence entry on the invoice timeline. The routine reuses in between leave no trace."
