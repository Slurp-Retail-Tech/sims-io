new:
  - title: "Invoice bills an expiry date that moved"
    detail: "A new Actions Required reason. The nightly run sweeps every open proforma, not just the outlets due tonight, and reports any whose lines no longer bill the date their outlet renews from. The entry names the invoice, both dates, and links straight to the document so it can be voided. It is informational, never blocking, so the correct proforma for the new date is still raised the same night."

  - title: "Entries clear themselves"
    detail: "The report closes on its own once the invoice is voided, paid, or the dates come back into line. Nothing has to be ticked off by hand."
