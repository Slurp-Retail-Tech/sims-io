new:
  - title: "Assign plan"
    detail: "The Plan Catalog has an Assign plan button. Pick a plan, type the franchise id, and SIMS resolves the merchant name back for confirmation, exactly as the Contacts mapping dialog does. Choose the whole franchise or one of its outlets, set the default term, and optionally override either price with a reason. A large override goes to the approval queue rather than pricing anything, and the dialog says so when it saves."
  - title: "End an assignment"
    detail: "Each assignment has an End action. The outlets it covered fall back to the next scope, or to Actions Required if nothing remains."
improved:
  - title: "Assignments show names"
    detail: "The assignment list names the merchant and outlet alongside their ids, so you can tell which franchise a row is about without opening another page."
