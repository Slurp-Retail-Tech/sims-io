date: "2026-08-30"
title: "Startup no longer demands optional settings"
summary: "The new startup configuration check was too strict: it treated several genuinely optional settings as required, and treated a feature switched explicitly off as switched on. Both prevented the application from starting."
fixed:
  - title: "Optional ClickUp field mappings are no longer required"
    detail: "The optional mappings that connect ticket fields to ClickUp custom fields were treated as mandatory whenever ClickUp was configured at all, so an installation using ClickUp without those mappings refused to start. They are optional by design — an unmapped field is simply not sent — and are treated that way again."
  - title: "A feature switched off is no longer read as switched on"
    detail: "Settings that turn an integration on or off hold the text \"false\" when disabled. The check only looked at whether they had a value, not what the value was, so a disabled Google Calendar or Google Places integration was read as enabled and its full configuration demanded. An explicit off value is now understood as off."
  - title: "The optional survey webhook secret is no longer required"
    detail: "The shared secret for the survey link webhook was treated as mandatory once the webhook address was set. It is optional — the header is only sent when it is present."
