version: "4.11.0"
date: "2026-09-15"
title: "Renewal dates become ours to keep"
summary: "Groundwork for automated renewals. Licence expiry dates now live in a record Slurp owns, rather than only inside the nightly merchant import, so a renewal can extend a date and have it survive until morning. Nothing changes on screen yet; the renewal catalog and reminders follow in the next releases."
new:
  - title: "Every outlet now has a subscription record"
    detail: "Each outlet gets its own renewal record holding the company and outlet name, the licence expiry date, who bills it, and whether it is on hold. It is filled in automatically from the merchant import, including outlets imported for the first time, so nobody has to create one by hand. Test accounts and closed accounts are left out and will never enter a renewal cadence."
  - title: "An expiry date a renewal can actually change"
    detail: "The nightly merchant import replaces everything it knows about an outlet, so any change made elsewhere to a licence expiry date was overwritten before anyone saw it. Expiry dates now sit in the new subscription record instead. The import fills one in the first time it sees an outlet and keeps it current until that outlet is renewed; from the first renewal onwards the date belongs to Slurp and the import leaves it alone."
  - title: "Renewals made outside the system are flagged, not overwritten"
    detail: "If the point-of-sale system reports a later expiry date than the one a renewal set, somebody renewed that outlet elsewhere. Rather than silently choosing one date and discarding the other, the run records both and reports the disagreement so a person can decide which is right."
  - title: "A price list for subscriptions"
    detail: "Subscription plans can now be stored as a reusable price list, each holding a licence tier and both an annual and a six-month price, and assigned either to one outlet or to a whole franchise. An outlet opened later automatically picks up its franchise's plan, with no further action. The screens for managing all of this arrive in the next release."
improved:
  - title: "Finding which outlets are expiring no longer reads every outlet"
    detail: "Answering \"which outlets expire soon\" previously meant loading every outlet in the database and sorting through them in memory on each request. Expiry dates are now stored in a form that can be looked up directly, which is what makes a nightly reminder schedule practical."
