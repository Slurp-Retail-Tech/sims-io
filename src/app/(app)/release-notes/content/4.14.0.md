title: "Renewal invoices raise themselves"
summary: "A nightly job now finds the outlets coming up for renewal, raises a proforma invoice for each, and records the specific reason for every one it could not. Nothing is sent to merchants yet — this release is about seeing the full picture before anyone is contacted."
new:
  - title: "Renewals are found without anyone remembering to look"
    detail: "A nightly job reads every subscription's expiry date and picks up the ones falling due at each reminder point, fifteen, five and one day ahead by default. It matches those dates exactly rather than scanning a range, so a night the job does not run does not cause three groups of merchants to be invoiced at once the following day."
  - title: "Proforma invoices, numbered and priced automatically"
    detail: "Each due renewal gets a proforma with its own number in the existing format, priced from the plan catalog including any agreed override, with the renewal period running from the current expiry date rather than from today. Running the job again reuses the invoice already raised instead of issuing a second one, so the later reminders refer to the same document and the same number."
  - title: "One invoice for a franchise renewing together"
    detail: "Where a franchise is set to be billed as a group, every outlet sharing an expiry date appears on a single invoice, one line each, with one total. Outlets in the same franchise expiring on a different date are invoiced separately. An outlet on hold, billed by a reseller, or held up by an unresolved issue is left off and recorded against the invoice, so the total can always be explained."
  - title: "An Actions Required queue, worked before the deadline"
    detail: "An outlet that cannot be invoiced is listed with the precise reason: no plan assigned, no price for the chosen term, a price override still awaiting approval, nobody accountable for the renewal, or a designated contact with no usable way of reaching them. Every problem is listed, not just the first, so one pass through the queue closes them all rather than revealing the next one a night later."
  - title: "Fixing the problem clears the entry"
    detail: "Entries resolve themselves. Assign the missing plan or name the missing contact, and the next night's run both removes the entry and invoices the outlet. Nothing has to be ticked off by hand. Each entry shows how many days remain before the licence expires, so the queue sorts by urgency rather than by age."
improved:
  - title: "Prices on an invoice explain themselves"
    detail: "Every line records the list price, the price actually charged, the difference, and which rule produced it. An amount can be accounted for months later without recalculating it against prices that may since have changed."
