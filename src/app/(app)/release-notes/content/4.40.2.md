version: "4.40.2"
date: "2026-10-08"
title: "ClickUp sync and PLUS update no longer report false failures"
summary: "Like the merchant import fix in 4.40.1, the ClickUp status sync and the PLUS update no longer answer with an error when their first batch fails after the work has already been queued."
fixed:
  - title: "Starting a ClickUp status sync no longer reports a false failure"
    detail: "If the first batch of a ClickUp status sync hit an error, the request reported that the sync had failed, even though it was queued and would retry. It now reports that the sync was accepted, and the error is saved on the run while it retries."
  - title: "The PLUS update page no longer stops on a single batch error"
    detail: "When one batch of a PLUS update hit an error, the page stopped with a generic \"Unable to advance the PLUS update\" message. It now reads the update's status instead, so it shows the real cause and the rows processed so far."
