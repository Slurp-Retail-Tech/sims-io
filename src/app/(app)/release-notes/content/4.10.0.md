date: "2026-08-30"
title: "Survey tokens are no longer stored in plain text"
summary: "Customer satisfaction survey links were still stored in readable form in the live database, despite an earlier security fix that only ever reached the schema file. They are now stored as an irreversible fingerprint, and the reference schema finally matches the live database."
security:
  - title: "Survey links are stored as a fingerprint rather than in the clear"
    detail: "A security review in April recorded this as fixed, but the fix only ever applied to the reference schema file — no database change was ever run, and the application quietly fell back to the readable form when it noticed the column was missing. Anyone who could read that table could therefore read live survey links and submit responses as the recipient. Each token now also has an irreversible fingerprint, which is what the application checks. Existing links keep working. The readable column remains for now so this release can be rolled back safely, and is removed in a follow-up once every link issued before today has expired."
fixed:
  - title: "The reference schema now matches the live database"
    detail: "The schema file described every identifier one way while the live database had drifted to another, so a fresh setup and production were subtly different databases. All 57 differing columns have been reconciled against a survey of the live database, leaving the 13 that genuinely differ untouched."
improved:
  - title: "Automated checks now test the database we actually run"
    detail: "The migration checks only ever ran against the reference schema — a shape that existed on no real server — so a change whose real target was production went untested. They now run against both, which is how the plain-text token issue would have been caught."
  - title: "One less lookup on every ticket and survey page"
    detail: "The application inspected the database's own structure before reading survey data, to cope with a column naming difference that no longer exists anywhere. That inspection has been removed."
