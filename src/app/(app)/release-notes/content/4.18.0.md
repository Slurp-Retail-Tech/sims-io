version: "4.18.0"
date: "2026-09-17"
title: "Renewal gaps surface 30 days early"
summary: "The nightly renewal run now checks every outlet expiring in the next 30 days for a plan and a PIC, not only the ones on a reminder date."
new:
  - title: "Readiness sweep"
    detail: "Until now an outlet only reached Actions Required on the exact night it was 15, 5 or 1 days from expiry, and only if something was wrong that night. The run now also looks at every outlet expiring inside a readiness window, 30 days by default, and checks the same conditions: a plan assigned, a renewal PIC designated, that PIC reachable. Anything missing appears in the queue weeks early and is re-checked every night. No invoice is raised by the sweep; that still happens on the reminder dates. The window is a setting, so it can be widened without a release."
fixed:
  - title: "Fixing a gap in one outlet no longer clears entries for another"
    detail: "Auto-resolution used to close every open entry in a franchise whenever any outlet in it was processed, so an entry raised for one outlet could vanish because a different outlet came due. Entries now resolve only when the specific outlet was re-examined and the gap is gone, and only for the reasons the nightly run actually evaluates. Entries raised by payment or messaging steps are left alone."
improved:
  - title: "Diagnostic shows the readiness window"
    detail: "The renewal queue diagnostic now reports how many subscriptions sit inside the readiness window, so an empty queue with nothing due can be told apart from an empty queue with nothing checked."
