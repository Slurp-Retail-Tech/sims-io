improved:
  - title: "The PLUS job table is no longer created at runtime"
    detail: "Every PLUS update job creation and every progress check ran a create-table-if-missing statement first. Besides the wasted round trip on a page that polls every 1.5 seconds, it meant the application account needed permission to change the database structure — something only the migration runner should be able to do. A survey of the production database confirmed the table is present, so the statement has been removed and the table is now owned by the schema and migrations alone."
